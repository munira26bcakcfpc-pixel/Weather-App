Project Overview

This is a Weather App UI Design created using Figma. The application provides a simple, clean, and attractive interface for users to check current weather conditions and forecast information. It includes weather details such as temperature, location, weather conditions, and forecast information.

🎯 Objective

The main objective of this project is to design a user-friendly weather application with a clean and modern interface that allows users to quickly understand the current weather and upcoming forecast.

✨ Features
🌤️ Current Weather Information
📍 Location Display
🌡️ Temperature Details
☁️ Weather Condition Display
📅 Weather Forecast
🌅 Weather Icons and Illustrations
📱 Mobile-Friendly Interface
🔄 Simple and Easy Navigation
🛠️ Tools Used
Figma
